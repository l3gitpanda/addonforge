New to addons? Start here

What an addon is. A small folder of text files (Lua and XML) that WoW loads when you log in. Addons can change how the interface looks and add helpers like boss timers or a better bag window. They cannot play the game for you, and on Forever a lot of combat information is deliberately hidden from them.

Where they live. Inside your WoW folder, under Interface\AddOns. Each addon is one or more folders in there. That is the only place AddonForge writes to. Your settings for each addon are kept separately in the WTF folder, which AddonForge never touches, so removing or updating an addon does not lose its settings.

Turning them on. Install from here, then start WoW. On the character-select screen there is an AddOns button in the corner: tick the ones you want and untick any you don't. Already in game? Type /reload in chat after installing to load them.

"Forever" builds. Forever uses a newer interface than Classic Era, so addons need a version made for it. AddonForge tells you which ones have one. An addon marked "not for Forever" may still load but can error or show nothing.

Updates. Open AddonForge now and then, or leave it to check when it starts. Authors publish a new version, you press Update, done. Pin an addon if you want to hold it at a version you like.

Beta note. The Forever beta has a bug where addon settings sometimes don't load on the next login. That is the game, not the addon. Some people use an addon called SVShim as a workaround until Blizzard fixes it; it is linked from the catalogue, and AddonForge will tell you when it is time to remove it.

WoW install

The product folder AddonForge manages: _forever_ for the live game, _classic_beta_ for the beta. Only WoW: Forever for now.

Updates

Installs whatever has an update as soon as the launch check finishes. Pinned and ignored addons are left alone.

For authors who only ship their Forever build as a GitHub pre-release. Uses the GitHub API for the check, limited to 60 requests an hour without a token.

This build does not update itself. It is a fork with no releases of its own yet, and it will not replace itself with the original AddonForge. Addon updates are not affected.

CurseForge

Searching and installing from CurseForge needs an API key of your own; CurseForge gives each key to one person and does not allow it to be shared, so AddonForge cannot ship one. Get a key from CurseForge, paste it here, and it is tested once before it is saved. It is kept in your system's credential store, never in the settings file, the log, diagnostics or an exported list, and is sent only to CurseForge: its API, and its download servers when a file is fetched. Addons whose authors turned off third-party downloads stay link only.

Addon list

Names and sources only, no settings. Import one to install everything on it.

Backups

Zips your game's WTF folder (addon settings, saved variables, key bindings) into Documents\AddonForge backups. AddonForge only reads it. To restore, close WoW and unzip over the WTF folder yourself.

Diagnostics

Builds a report with your version, install folder, addon list and the last few log lines, and copies it to your clipboard. Your Windows username and home folder are replaced with placeholders. Nothing is sent anywhere.


      

    


    

      
About

      

        
AddonForge  (private build).

        
No accounts, no ads, no analytics. Talks only to the addon sites (GitHub, CurseForge, WoWInterface, TukUI, and Wago for preview images). At launch it reads the catalogue and download totals from GitHub, then checks your installed addons for updates. This build does not look for updates to itself. CurseForge search and installs use your own API key (see CurseForge above); it is kept in your system's credential store and only ever sent to CurseForge's API and download servers. The only CurseForge data kept on disk is the project id and version name of what you installed.
